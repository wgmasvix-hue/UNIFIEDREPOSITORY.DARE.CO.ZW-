# DARE Strategy — Africa's Knowledge & Data Intelligence Infrastructure

## 1. Positioning

**DARE — Africa's Knowledge & Data Intelligence Infrastructure.**
Tagline: **Africa's Knowledge, Connected.**

"DARE connects Africa's research, data and knowledge so people can
discover, understand and use it." Supporting concepts: Discover African
knowledge. Find African data. Explore African research. Ask DARE.
Use evidence.

## 2. Advantage (why not a generic AI)

African knowledge + African datasets + African research + African
institutions + African researchers + African geographic context + African
languages + AI grounded in those sources. We are not building the biggest
model; we are building intelligence around African knowledge, data and
realities: Repository + Discovery engine + Knowledge graph + Data
intelligence + Grounded AI.

## 3. Architecture (see DARE_ARCHITECTURE.md)

African Sources → Harvest → Unified Repository (authoritative) →
Intelligence (index) → Graphs → DARE AI → People. Full product map:
DARE_PRODUCT_MAP.md. Platform rules: DARE_PLATFORM_CONTRACT.md.

## 4. Data and language posture

Datasets first-class (see AFRICA_DATA_STRATEGY.md); 54-country taxonomy
with RECs, no inferred geography; languages by infrastructure, not
marketing (detection → multilingual metadata/search → translated
summaries; source language preserved).

## 5. UX direction (Library as front door)

"Search African knowledge…" + Ask DARE; browse Research/Datasets/Books/
PDFs/Institutions/Researchers/Countries/Topics; feature African Data,
African Research, African Open Knowledge. Repository discovery central —
never a generic chat app. Current Angular H1 ("Discover African Knowledge")
already points this way; messaging converges on §1 as surfaces evolve.

## 6. Success criteria (demonstration path)

Find an African dataset → related research → responsible institution →
geographic coverage → open the original → ask DARE → grounded cited
answer → derived study/research content → original preserved. The goal: an
infrastructure layer making African evidence discoverable, connected,
machine-readable and useful to people and AI.
